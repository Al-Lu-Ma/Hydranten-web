# Hydranten-Übung – Betreuer-Ansicht (Web)

**Link:** https://al-lu-ma.github.io/Hydranten-web/

Nur-Lesen-Ansicht für Betreuer (iPhone, Android, Browser). Keine Installation nötig.

## Anmelden
- **Name** des Betreuers (genau wie im Team-Tab der App eingetragen)
- **PIN** (5 Ziffern) – steht bei der Einsatzleitung in der App: Team-Tab → Cloud-Abgleich

Tipp auf dem iPhone: Link in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

## Hinweise
- Die Seite enthält selbst keine Daten. Alles kommt verschlüsselt (AES-256) von der Einsatzleitung.
- Die Einsatzleitung muss den **Cloud-Abgleich** eingeschaltet haben.
- Änderungen aus dem Browser werden nie in die App übernommen (nur Lesen).
